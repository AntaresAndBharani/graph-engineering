### Fixed
- Fixed **Closed-Issue Guarding, Automatic Parent Story Completion & SDLC Memory Reconciliation (`orchestrator/poller.py`, `orchestrator/db.py`, `orchestrator/nodes/devtest.py`, `tests/test_poller.py`, `tests/test_db.py`, `tests/test_nodes.py`)**: Added `state` and `closedAt` to GitHub issue fetching JSON payloads across `fetch_issue_by_number`, `fetch_issues_with_label`, and `fetch_all_open_issues`. Equipped DevTest Phase 3 with a pre-execution closed-issue guard that immediately aborts, removes stale `ready-for-dev`/`queued` labels via GitHub CLI with graceful subprocess error handling, synchronizes `state = 'CLOSED'` into SQLite, and avoids invoking LLM coding harnesses on closed/merged issues. Implemented pure `StateManager.reconcile_completed_stories` (marking parent stories `CLOSED` with `dev-implemented` when 100% of child subtasks are completed) and `StateManager.reconcile_untracked_closed_issues` with completeness threshold protection in `poll_project_sdlc_items`. Hardened `get_next_devtest_task` and `ActiveStory` CTE query to strictly eliminate parent story dispatch and exclude parent stories from standalone task fallbacks.
- Fixed **DevTest Subtask Resolution & Strict FIFO Story Ordering (`orchestrator/db.py`, `orchestrator/nodes/devtest.py`, `tests/test_db.py`)**: Fixed an issue where `StateManager.get_next_devtest_task` returned `None` when the lowest open child subtask under an active user story was labeled `queued` (or `status:queued`, `status:awaiting-approval`), causing DevTest to deadlock in an infinite idle sleep. DevTest now deterministically resolves the lowest open subtask in the oldest open User Story (holding the lock on in-progress work and quarantined blocked stories), automatically activates queued subtasks to `ready-for-dev` upon pickup, and strictly finishes the oldest User Stories first. Added `test_get_next_devtest_task_picks_lowest_open_queued_subtask_in_oldest_story` and updated all config models with `OrchestratorBaseModel` for full hot-reload resilience.
